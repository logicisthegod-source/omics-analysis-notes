# Omics Analysis Notes

Learning notes and practical scripts for transcriptomics and metabolomics data analysis.

## Contents
- `R/` - R scripts for differential expression and visualization (ggplot2, patchwork)
- `python/` - Python scripts for data processing (pandas)

## Topics
- RNA-seq differential expression analysis
- qPCR relative quantification (2^-ddCT method)
- Metabolomics data processing and statistics
- Publication-ready data visualization

## Tools
R, Python, ggplot2, DESeq2, pandas, ImageJ
